# Offer Never Comes

**Live:** https://skyspeak.github.io/offer-never-comes/

A dopamine site for the job search. Browse seats you could grow into, plan the path, and file an application that is never sent. In the spirit of the Korean sites where you track a courier and the food never arrives.

## What you can do

- Browse sixteen invented seats. Each one has a pay band, a Tuesday, three reviews, and a path in.
- Filter by appetite: money, craft, status, or freedom. Or sort by the shortest path.
- Plan to be in a seat. Check the steps. They stay in this browser.
- Apply on paper: a chapter, one sentence, one resume line. A recruiter walks the loop. The letter is stamped not sent.
- The end card counts the hours and the one rejection you skipped. Applications sent: 0.

Nothing here is a real opening. Nothing you submit is sent. Plans and letters stay in `localStorage`.

## Run locally

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.
